# 庄Sir的状态栏

**把 Mac 的关键状态放进右上角，但不打扰你。**

庄Sir的状态栏是一款轻量、漂亮、常驻菜单栏的 Mac 状态监控工具。它会用最简洁的图标和数字告诉你：电脑是否吃紧、网络是否在跑、硬盘空间是否安全。

它适合每天长时间使用 Mac 的创意团队、剪辑师、设计师、运营同学、产品经理和开发者。你不需要懂任何技术，打开后看右上角就可以。

## 你会看到什么

- **内存占用**：快速判断电脑卡顿是不是因为内存压力。
- **实时网速**：分别查看上传和下载是否正在占用网络。
- **硬盘状态**：一眼看到磁盘使用比例和剩余空间。
- **CPU 负载**：了解当前系统是否在高负载运行。
- **电池状态**：在 MacBook 上查看电量和充电状态。

## 菜单栏只保留最重要的一个信号

庄Sir的状态栏把菜单栏显示压缩到尽可能短：一个图标加一个核心数字。

你可以在主界面中直接点击中间 5 个状态按钮，快速切换菜单栏当前关注：

- 内存
- 网速
- 硬盘
- CPU
- 电池

如果你只想让它关注其中几项，也可以直接关闭对应按钮下方的小开关。关闭后该项会变灰，主界面也会把它从详细检测卡片中隐藏。

## 点击后看到完整细节

点击右上角的庄Sir的状态栏，可以打开深色主界面。

你可以在这里：

- 点击 5 个状态按钮，切换菜单栏显示内容
- 打开或关闭某一项检测
- 显示或隐藏菜单栏数字
- 调整刷新频率
- 横向浏览所有已开启的详细卡片
- 点击卡片打开旁边的详情窗口，查看进程排行或占用明细

庄Sir的状态栏会记住你的选择，下次打开还是你的配置。

## 安静运行，不抢电脑资源

它会根据你正在看的内容自动调整检测频率：

- 主界面关闭时，只更新菜单栏当前显示的项目
- 详情窗口关闭后，立即停止对应的进程排行检测
- 硬盘目录只在需要时扫描，并短暂缓存结果
- Mac 进入低电量模式后，自动降低后台刷新频率

你不需要配置这些规则。它会在保持数据清晰及时的同时，尽量减少 CPU 唤醒和电量消耗。

## 为什么做它

很多系统监控软件很强，但界面复杂、信息密度高、普通用户不容易马上看懂。

庄Sir的状态栏的目标是反过来：把最重要的信息放到最靠近眼睛的位置，只保留真正有用的判断信号。需要更多细节时，再点击展开。

## 安装和使用

1. 下载最新版本的 zip 包。GitHub 附件名为 `ZhuangSir-StatusBar-0.5.0.zip`。
2. 解压后得到 `庄Sir的状态栏.app`。
3. 双击打开。
4. 打开后它会出现在 Mac 右上角菜单栏。

如果 macOS 第一次提示无法确认开发者，请在 `庄Sir的状态栏.app` 上点右键，选择“打开”，再确认一次。这是团队内部分享版的常见提示。

## 系统要求

- macOS 14 或更新版本
- Apple Silicon Mac（M1 或更新芯片）

## 隐私说明

庄Sir的状态栏只读取本机系统状态，例如内存、磁盘、网络流量计数、CPU、电池状态，以及用于详情排行的本机进程资源占用。

它不会上传你的文件、不会读取你的文档内容、不会收集个人信息。

## 当前版本

**0.5.0**

这是低功耗优化版本。关闭主界面或详情窗口后，庄Sir的状态栏会立即停止不再需要的检测；平时只更新菜单栏当前关注的数据。硬盘详情不再反复扫描文件夹，低电量模式也会自动放慢刷新频率。

网速详情继续显示实时上下行、当前占用网络最多的进程和累计流量。详情窗口右上角新增刷新按钮，需要时可以立即获取最新结果。
