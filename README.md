# PulseBar

**把 Mac 的关键状态放进右上角，但不打扰你。**

PulseBar 是一款轻量、漂亮、常驻菜单栏的 Mac 状态监控工具。它会用最简洁的图标和数字告诉你：现在电脑是否吃紧、网络是否在跑、硬盘空间是否安全。

它适合每天长时间使用 Mac 的创意团队、剪辑师、设计师、运营同学、产品经理和开发者。你不需要懂任何技术，打开后看右上角就可以。

## 你会看到什么

- **内存占用**：快速判断电脑卡顿是不是因为内存压力。
- **实时网速**：查看上传、下载是否正在占用网络。
- **硬盘状态**：一眼看到磁盘使用比例和剩余空间。
- **CPU 负载**：了解当前系统是否在高负载运行。
- **电池状态**：在 MacBook 上查看电量和充电状态。

## 菜单栏只保留最重要的一个信号

PulseBar 0.2.0 把菜单栏显示压缩到尽可能短：一个图标加一个核心数字。

你可以选择菜单栏当前关注：

- 内存
- 网速
- 硬盘
- CPU
- 电池

这样它不会长时间占住右上角，也更不容易在菜单栏拥挤时被系统隐藏。

## 点击后看到完整细节

点击右上角的 PulseBar，可以打开主界面。你可以选择哪些信息显示在菜单栏上：

- 选择菜单栏焦点指标
- 显示或隐藏详细指标卡片
- 开启或关闭百分比标签
- 调整刷新频率

PulseBar 会记住你的选择，下次打开还是你的配置。

## 为什么做它

很多系统监控软件很强，但界面复杂、信息密度高、普通用户不容易马上看懂。

PulseBar 的目标是反过来：把最重要的信息放到最靠近眼睛的位置，只保留真正有用的判断信号。需要更多细节时，再点击展开。

## 安装和使用

1. 下载 `PulseBar-0.1.0.zip`。
2. 解压后得到 `PulseBar.app`。
3. 双击打开。
4. 打开后它会出现在 Mac 右上角菜单栏。

如果 macOS 第一次提示无法确认开发者，请在 `PulseBar.app` 上点右键，选择“打开”，再确认一次。这是团队内部分享版的常见提示。

## 系统要求

- macOS 14 或更新版本
- 支持 Apple Silicon 和 Intel Mac 的 Swift 原生构建

## 隐私说明

PulseBar 只读取本机系统状态，例如内存、磁盘、网络流量计数、CPU 和电池状态。

它不会上传你的文件、不会读取你的文档内容、不会收集个人信息。
